# QUERY - answer from the wiki (with citations, compounding)

## When to use

Activate when the user asks about or wants to mine the knowledge in the Second Brain, e.g. "synthesize the
frameworks about X", "compare A vs B vs C", "what does the wiki have on Y".

Five ways to mine: synthesis, comparison, hypotheses, listing, visualization. Always answer
with citations and save results of value.

1. Read `wiki/index.md` FIRST to know which pages exist.
2. Read the relevant wiki pages (by group/name); read pages that are `[[link]]`ed when you need full context.
3. If something is missing -> read the matching `sources/`. Still missing -> append 1 line to `wiki/_open-questions.md`.
4. Answer with a `[[citation]]` for every specific claim. Say clearly where the wiki does not cover something instead of making it up.
5. If the answer has REUSABLE VALUE (a comparison, an analysis, a new mapping) -> propose saving it as a new wiki page (compounding: discoveries also accumulate in the brain instead of dissolving into chat history).

7 kinds of high-quality questions: Synthesis (comparison table) · Compare 3+ (matrix) · Hypothesis (impact analysis) · Labeling/listing · Visualization (canvas/diagram) · Translation/conversion · Self-check for gaps (append to open-questions).
