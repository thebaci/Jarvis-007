# Team chat group: T0 and T1 plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- T0: move the Resonance switch onto each assistant row of the Collaborators page (one place only), sync two tabs, and show success only when the server confirms.
- T1: the core of the team chat group in Limited permission mode.

**Architecture:** T0 adds no route.
- The assistant list reads `GET /resonance/agents` once, at the same time as `/agents`, then joins by slug.
- The switch calls the A1 route `POST /resonance/agents/toggle` as is.
- The server broadcasts a `resonance_agents` packet through `ChatRuntime.publish` so other tabs reload.
- The duplicate switches in the right column and on the Settings page are removed.
- T1 follows architecture A of the spec, section 3.

**Tech Stack:** Python 3.12 (FastAPI, SQLite), plain JS in `dashboard/`, Python tests in `tests/python/*.py` and node tests in `tests/js/*.js` via `python tests/run.py`.

**Spec:** [2026-10-13-team-chat-design.md](../specs/2026-10-13-team-chat-design.md) (D1 to D7 settled).

## Global Constraints

- Version 0.110.0 for T0 (reserved at `f972ee4c`). T1 reserves its own number when it starts.
- New identifiers in English; comments, UI text and docs in Vietnamese with diacritics.
- No em dash (U+2014) anywhere.
- New on-screen text has keys in both `dashboard/i18n/vi.json` and `en.json`; `en.json` has no Vietnamese text; never address the user as "anh".
- Python writes files with `encoding="utf-8", newline="\n"`.
- No real model calls; every test uses a fake engine.
- No merging, no touching the VPS.
- The A1 contract stays as is: only the owner turns it on or off; `missing` needs confirmation; turning off is always allowed.

## Review Focus

1. **Clicking the switch twice very fast:** the second click does not send while the first is unfinished (the switch is locked while saving).
2. **Server returns 409 (agent `missing` or needs confirmation):** the switch shows the real state after reload, not the state the user just clicked.
3. **`GET /resonance/agents` fails or is slow:** the assistant list still shows; the row has no switch (the state is not guessed).
4. **Assistant name with HTML characters:** the aria label and the confirmation box do not inject HTML.
5. **Another tab changes the state:** this tab updates from the WebSocket packet, no F5 needed.

```js
  /* T0 team chat group (spec section 10): the Resonance state of ONE assistant in words, for the row in the left column of the Collaborators page. */
  function stateKey(row) {
    var r = row || {};
    if (r.status === "missing") return "resonance.t0_state_missing";
    if (r.status === "retired") return "resonance.t0_state_retired";
    return r.enabled && r.status === "active" ? "resonance.t0_state_on" : "resonance.t0_state_off";
  }

  /* The switch on the assistant row. With no data, draw nothing: do not guess the state. `missing` has no on box but has
     a button that opens the right panel, where the two A1 confirm buttons live. */
  function rowToggleHtml(row, opts) {
    if (!row || !row.slug) return "";
    var o = opts || {};
    var key = stateKey(row);
    var label = o.saving ? tw("resonance.t0_saving") : tw(key);
    if (row.status === "missing" || row.status === "retired") {
      return '<button type="button" class="ws-rs ws-rs-confirm" data-rs-open="' + esc(row.slug) + '">' +
        '<span class="ws-rs-text">' + esc(label) + "</span></button>";
    }
    var on = !!row.enabled && row.status === "active";
    return '<label class="ws-rs" title="' + esc(tw("resonance.t0_toggle_aria", { name: row.name || row.slug })) + '">' +
      '<span class="ws-rs-text">' + esc(label) + "</span>" +
      '<span class="toggle"><input type="checkbox" class="ws-rs-toggle" data-rs="' + esc(row.slug) + '"' +
      ' aria-label="' + esc(tw("resonance.t0_toggle_aria", { name: row.name || row.slug })) + '"' +
      (on ? " checked" : "") + (o.saving ? " disabled" : "") + "><span></span></span></label>";
  }

  /* Ask again before turning OFF when the assistant still has open goals (A1 contract: stop at the next step). None means no question. */
  function offConfirmText(row) {
    var n = Number((row || {}).goals_open || 0);
    if (!row || !row.enabled || n <= 0) return "";
    return tw("resonance.t0_off_confirm", { name: row.name || row.slug, n: n });
  }
```
