PILOT LIMITS AND BUDGET

Provider and model (suggested default: provider "Anthropic API" for all 3 teams; the owner picks the exact model on the
Models page before the run and records it in the report)
  - Recommended: Claude Code with an Anthropic API KEY, or an API model (OpenRouter, OpenAI API). Reason: the pilot runs
    in the background for several days; the Anthropic Pro/Max plan is meant for ordinary personal use, and running 24/7
    in the background or on a VPS risks the account being locked. The xAI plan has not spelled this out either.
  - Claude Code can run at the "needs approval" permission level when the claude-agent-sdk build has the PreToolUse hook
    (the build pinned in requirements.txt has it); without it, Jarvis 007 refuses the step and says so clearly.
  - Codex (ChatGPT plan) can run at the "needs approval" permission level when: MCP Hub is on, Codex's own sandbox is on
    (do NOT set JAVIS_CODEX_SANDBOX=off, so in Docker without bubblewrap Codex cannot be used for approval-gated teams), and
    ~/.codex/config.toml has no MCP of its own outside Jarvis 007.
  - Do NOT use Grok Build or Antigravity for a team at the "needs approval" permission level: Jarvis 007 refuses a step
    with tools on these two engines (it cannot block them before they run). To use them you must turn on "The team acts
    without asking", and then there is no approval gate.

Default budget for each team (set in the Group tab > Advanced and in the Department mandate section). config/teams.json sets
its own values per team and WINS over the numbers below when they differ.
  daily_turns (replies per day)                    40
  task_turns (replies per job)                     12
  task_steps (steps per job)                       8
  observe_per_day (mandate observations)           24
  jobs_per_day (jobs the mandate opens by itself)  2
  max_open_jobs (stop opening when this many open) 3
  fix_rounds (acceptance fix rounds)               2
  Server-wide ceiling: JAVIS_RESONANCE_CALL_CEILING (for example 300 calls per day for the whole pilot machine).
  Cost: set a spending limit on the API provider's page before the run (for example 5 USD per day).

Stop immediately (emergency stop, see run_guide.txt)
  - Any outside action runs without a matching approved request (compare the trace against the hub log).
  - A job becomes "done" while an approval request is still pending, or it has acceptance criteria that are not met.
  - The mandate opens a job outside its assigned sources or exceeds jobs_per_day.
  - One day's cost exceeds 2 times the budget, or the shared call ceiling reaches 100%.
  - The same step fails more than 3 times in one day.

Permissions
  - Teams 1 and 2: "Needs your approval". Team 3: "Needs your approval" for the first 3 days, after which the owner may try
    "The team acts without asking" if there were no violations (record when it was changed).
  - Test source: only check commands the owner wrote (run at the Draft writes level of the Coding page, which can run code).
